# 2025-2026 영향력 있는 멀티모달/text→image retrieval 논문 — 우리 프로젝트 적용성 리포트

> **검증 기준**: 아래 모든 논문은 Semantic Scholar Graph API(또는 Google Scholar 교차검증)로 인용수 50회 이상이 확인됨. 우리 프로젝트의 3대 발견을 기준으로 적용성을 판정한다 — **(F1)** N=30 gold eval의 통계적 검정력이 진짜 천장이라 어떤 방법도 LoRA+BM25를 유의하게 못 이김, **(F2)** 한국어 char-ngram BM25 lexical fusion이 지배적 레버, **(F3)** training-free 테스트타임 보정(modality-gap / QB-Norm·CSLS / query-bank prior)만 작지만 일관되고 high-power-유의한 이득.
>
> **코드 확인 사실**: 저장소에 `maxsim.py`(ColBERT식 Sum-of-MaxSim), `patch_rerank.py`, `precompute_vision_patches.py`, `hybrid_retrieval.py`(BM25 fusion), `query_expansion_eval.py`가 이미 존재. 즉 **late-interaction·하이브리드·쿼리확장은 이미 우리 SigLIP2 위에서 시도된 레버**다. 이 사실이 여러 판정을 강화한다.

판정 범례: **YES**(돌릴 가치 있음) / **PARTIAL**(아이디어 일부만, 보통 인용·작은 실험) / **NO**(인용만, 실행 부적합).

## 테마 1 — VLM-as-Embedder 백본 (디코더 VLM을 임베더로)

우리에게 가장 "현대적 강한 baseline"이 될 수 있는 그룹. 핵심 트레이드오프는 동일하다: cached frozen SigLIP2 + 초경량 text-only LoRA 경제성을 버리고 4~7B 디코더 VLM forward로 대체하느냐. (F1) 때문에 백본 교체가 gold에서 유의하게 이길 가능성은 낮다.

### 1. GME: Improving Universal Multimodal Retrieval by Multimodal LLMs
- 출처/인용: arXiv 2412.16855, arXiv.org (2024) · **140회**
- 아이디어: Qwen2-VL(2B/7B) 기반 범용 멀티모달 임베더. 마지막 토큰 hidden state를 임베딩으로. VLM2Vec 대비 기여는 **fused-modal(이미지+텍스트) 합성 학습 데이터 파이프라인** + UMRB 벤치마크. 오픈 instruct 가중치 배포.
- **우리 적용 판정: PARTIAL→YES(가장 돌릴 만한 백본)**. 이유: 우리가 이미 Qwen2.5-7B를 vLLM로 돌리므로 **학습 0, zero-shot 평가 가능** — 588 갤러리 이미지 한 번 임베딩, 한국어 쿼리 임베딩, cosine 랭크. "현대 강한 baseline" 한 줄로 정당. **비용**: 갤러리 588장 1회 인코딩(저렴) + 쿼리당 7B forward(느리지만 N=30/1706이라 감당). **기대값(F1)**: gold에서 유의하게 더 좋다/나쁘다 둘 다 못 보일 가능성 큼. 단일 dense라 (F2) BM25 레버를 버리므로 **반드시 BM25 fusion과 함께** 돌려야 공정. 한국어 짧은 슬랭 패션 쿼리에서 Qwen2-VL 성능은 미검증 리스크.

### 2. VLM2Vec: Training VLMs for Massive Multimodal Embedding Tasks
- 출처/인용: arXiv 2410.05160, **ICLR 2025** · **176회**
- 아이디어: InfoNCE 대조학습으로 임의의 디코더 VLM(Phi-3.5-V/LLaVA/Qwen2-VL)을 instruction-aware 범용 임베더로. interleaved 이미지+텍스트+instruction의 마지막 토큰 = 고정차원 벡터. MMEB 벤치마크 정립. GME/MM-Embed/mmE5/LamRA의 원형(canonical recipe).
- **우리 적용 판정: NO(프레이밍·baseline 인용만)**. 이유: drop-in이 아님 — frozen SigLIP2를 4~7B 디코더로 교체 + **대조학습 필수(training-free 아님)**. 강점인 instruction-following·interleaved 입력을 우리의 짧은 캐주얼 한국어→상품이미지가 거의 안 씀. (F1) 천장에서 전면 재엔지니어링 비용 대비 이득 기대 0에 가까움. **용도**: "우리는 1주/소규모 체제라 더 싼 dual-encoder+LoRA를 택했다"는 method-section 정당화 인용.

### 3. MM-Embed: Universal Multimodal Retrieval with Multimodal LLMs
- 출처/인용: arXiv 2411.02571, **ICLR 2025** · **131회**
- 아이디어: MLLM(LLaVA식)을 16태스크/10데이터셋에 bi-encoder로 파인튜닝, M-BEIR SOTA + MTEB 텍스트 검색 보존(continual FT). 우리에게 의미 있는 두 아이디어: (a) modality-aware **hard-negative mining**, (b) **off-the-shelf MLLM을 zero-shot reranker로 프롬프팅**(어렵/모호 쿼리에서 가장 도움).
- **우리 적용 판정: PARTIAL→YES(reranker 실험 1건)**. retriever 본체는 무겁고 학습 필요 → 패스. **저비용 이식 가능 아이디어 = zero-shot MLLM reranker**: LoRA+BM25 top-k(30 또는 1706 합성 쿼리)를 로컬 EXAONE-3.5-7.8B/Qwen2.5-7B에 caption+이미지 listwise/pointwise 판정. training-free, 로컬·무API 제약 충족. 논문의 "어려운/모호한 쿼리에서 도움" = 우리 진단(실패는 perception/label artifact)과 일치. **기대값**: gold N=30에선 무유의, **1706 합성 eval에선 high-power-유의 가능** — (F3)의 training-free-보정 승리 패턴과 동형.

## 테마 2 — Prompt-based / 텍스트-only 임베딩 (우리 thesis의 외부 검증)

### 4. E5-V: Universal Embeddings with Multimodal LLMs
- 출처/인용: arXiv 2407.12580 (2024) · **110회**
- 아이디어: MLLM에 "Summarize ... in one word:"로 입력을 한 단어로 압축시키고 그 토큰 표현을 읽어 modality gap을 줄임. 헤드라인: **텍스트 쌍만으로 학습해도 풀 멀티모달 대조학습에 필적/상회, 학습비용 ~95% 절감**. 파인튜닝 없이도 작동.
- **우리 적용 판정: PARTIAL(강한 지지 인용 + 선택적 임베딩 추출)**. 이유: **"텍스트 쌍만 학습으로 충분"이 우리 text-only LoRA 결정의 독립적 외부 검증** — 중심 설계 주장 정당화에 인용 강추. "한 단어로 표현" 프롬프트 + 토큰 읽기는 EXAONE/Qwen으로 LLM-side 텍스트 임베딩을 거의-training-free로 뽑는 길이고 **modality-gap 명시적 해소 프레이밍이 우리 modality-gap 보정과 직접 연결**. 단 이미지측은 여전히 MLLM forward 필요 → cached SigLIP2 대체라 백본 스왑은 비권장. 방어적 용도는 **지지 인용**.

### 5. LamRA: Large Multimodal Model as Your Advanced Retrieval Assistant
- 출처/인용: arXiv 2412.01720, **CVPR 2025** · **92회**
- 아이디어: 하나의 MLLM이 retrieval+rerank 둘 다. Stage1 텍스트-only 대조 사전학습(summarization-prompt 임베딩), Stage2 instruction-tuning 통합 임베더. 별도 **LoRA reranking 모듈**이 pointwise/listwise + hard-sample mining.
- **우리 적용 판정: PARTIAL(reranker 설계 모방 + 인용)**. 두 takeaway: (1) retrieval+rerank-in-one-MLLM 설계가 다시 **로컬 LLM으로 top-k MLLM reranking**을 지지(MM-Embed와 동일 실험), **hard-sample-mining listwise** 프레이밍이 빠른 rerank pass의 모방 대상. (2) 아키텍처는 우리보다 무거움(2-stage 임베더 + 자체 reranker LoRA) → 1주/소규모/천장 모두 부적합. **용도**: "base retriever 위 LoRA reranking" + VLM-as-retriever 지형 인용. 실행 슬라이스는 listwise LLM reranker만.

## 테마 3 — Late-Interaction / 멀티벡터 vs 단일벡터 (우리가 이미 시도한 영역)

### 6. ColPali: Efficient Document Retrieval with VLMs
- 출처/인용: arXiv 2407.01449, **ICLR 2025** · **146회**
- 아이디어: 문서 페이지를 이미지로 보고 VLM(PaliGemma-3B)이 patch당 128d 멀티벡터(~1024개/페이지) 출력, ColBERT식 **MaxSim late-interaction**으로 미세 매칭. ViDoRe 벤치마크.
- **우리 적용 판정: NO(패러다임 인용, 구현 말 것 — 이미 변형 시도함)**. 이유: 우리는 frozen 588 갤러리에 **단일 pooled SigLIP2 벡터**를 보유. ColPali는 retrieval-tuned patch 토큰 + 그걸 출력하는 생성형 VLM 필요이고 이득이 **patch 벡터 대조 파인튜닝(non-training-free)**에서 나옴. 또 텍스트-in-이미지 문서 대상 — 우리 패션 사진엔 글자 거의 없어 핵심 단어매칭 기제가 안 먹음. **결정적으로 우리는 `maxsim.py`/`patch_rerank.py`로 SigLIP2 patch에 MaxSim을 이미 돌렸고 천장을 못 뚫음** → 백본·patch-LoRA 재학습은 (F1)이 인증 불가. 패러다임 인용만.

### 7. Document Screenshot Embedding (DSE)
- 출처/인용: arXiv 2406.11251, **EMNLP 2024** · **115회**
- 아이디어: ColPali의 단일벡터 반대편 — 문서를 스크린샷으로 렌더, VLM bi-encoder가 **하나의 dense 벡터**로. BM25 대비 top-1 +17pt, 슬라이드 nDCG@10 +15pt.
- **우리 적용 판정: NO(방어적 related-work 인용)**. 우리와 더 정렬(단일 pooled, bi-encoder, MaxSim 없음)되지만 여전히 스크린샷 임베딩용 VLM 대조학습 필요(우리 frozen pooled SigLIP2 아님). **용도**: 단일벡터가 경쟁력 있다는 증거 → 우리 단일벡터 SigLIP2+BM25 설계 정당화, "반드시 멀티벡터여야 한다"는 리뷰어 반박 차단. late-interaction 스킵 정당화 인용.

### 8. VISTA: Visualized Text Embedding for Universal Multi-Modal Retrieval
- 출처/인용: arXiv 2406.04292, **ACL 2024** · **78회**
- 아이디어: frozen 강한 텍스트 인코더(BGE)에 visual token 주입 → 텍스트/이미지/합성 단일벡터. **합성 composed 이미지-텍스트 데이터 생성** 전략, 다단계 학습. R@5 96.3%.
- **우리 적용 판정: NO(related-work 인용)**. late-interaction 각도엔 비껴남(단일벡터). 재사용 가능 아이디어는 **합성 composed-data 생성** — 우리 7k LLM 생성 쿼리와 개념적 평행. 단 인코더 학습 필요 + SigLIP2 버리고 BGE+visual-token 전환. "생성 데이터로 텍스트측 적응"이 정립 레시피란 positioning 인용. 구현 우선순위 낮음.

## 테마 4 — Test-Time Compute / Instruction-Trained Reranking & Retrieval

### 9. Promptriever: Instruction-Trained Retrievers Can Be Prompted Like LMs
- 출처/인용: arXiv 2409.11136, **ICLR 2025** · **56회**
- 아이디어: MS MARCO에서 LLM으로 인스턴스별 자유형식 relevance instruction + hard "instruction negatives"(고립 시 관련이나 instruction으로 무관해지는)를 ~500k 합성, Llama-2-7B bi-encoder 학습 → 쿼리타임 프롬프트로 steerable, phrasing-robust(+14.3 p-MRR FollowIR).
- **우리 적용 판정: PARTIAL(우리가 쓴 바로 그 레시피의 최강 인용)**. 이유: **LLM 생성 user-style 쿼리로 retriever 학습 = 우리가 한 것** → 합성-쿼리 학습이 정당·정립됐다는 강한 방법론 인용. 텍스트-only지만 modality-agnostic, 우리 text-tower LoRA에 깔끔히 전이. 단락 가치 있으나 (F1/1주)로 **구현 비권장**인 두 아이디어: (a) 인스턴스-레벨 instruction, (b) hard instruction-negatives. phrasing-robustness 이득 = "user-query/caption gap이 레버"라는 우리 주장과 공명. **동기부여 인용, 재학습 말 것.**

### 10. Rank1: Test-Time Compute for Reranking in IR
- 출처/인용: arXiv 2502.18418, **COLM 2025** · **66회**
- 아이디어: ~600k DeepSeek-R1 추론 트레이스를 pointwise reranker로 증류, relevance 판정 전 명시적 CoT 출력. 추론 compute↑ → reasoning-IR(BRIGHT)·부정(NevIR)·instruction(mFollowIR) SOTA.
- **우리 적용 판정: NO(F3 프레이밍 인용)**. 이유: 텍스트-only passage IR, ~600k 추론트레이스 SFT + 7B+ reasoning 백본 필요 → 1주/training-free선호/N=30 전부 밖. **재현 금지**. **용도**: test-time-compute reranker 동기부여 + 우리의 싼 training-free 보정(modality-gap, QB-Norm/CSLS, query-bank prior)을 "예산 적정 analogue"로 positioning하는 (F3) 핵심 인용. 실험가치 ~0, 인용가치 높음.

## 테마 5 — Training-Free LLM-Routed Retrieval & Instruction Retrieval

### 11. CIReVL: Vision-by-Language for Training-Free Compositional Image Retrieval
- 출처/인용: arXiv 2310.09291, **ICLR 2024** · **125회**
- 아이디어: 학습 없이 — (1) VLM이 reference 이미지 캡션, (2) frozen LLM이 캡션+수정텍스트를 target 캡션으로 rewrite, (3) frozen CLIP text→image 검색. **"쿼리를 LLM으로 라우팅 후 frozen 대조모델로 검색" 템플릿** 정립.
- **우리 적용 판정: PARTIAL(정신적으론 직접, 형식은 아님 — 문헌 anchor)**. CIR이라 reference 이미지를 가정하는데 우리 순수 텍스트 쿼리엔 없어 파이프라인 비전이. 하지만 **핵심 move(frozen LLM으로 쿼리 rewrite/expand 후 frozen 인코더로 검색)가 우리가 선호하는 training-free, no-backbone-training 레버 그 자체** → 우리 LLM 생성 쿼리뱅크 + query-bank-as-prior를 정립 방향으로 프레이밍하는 가장 깔끔한 인용. 실행가치 낮음(reference 없음, 쿼리별 rewrite는 N=30서 무유의).

### 12. MagicLens: Self-Supervised Image Retrieval with Open-Ended Instructions
- 출처/인용: arXiv 2403.19651, **ICML 2024 (Oral)** · **119회**
- 아이디어: open-ended instruction을 따르는 단일 dual-encoder. 같은 웹페이지 공기 이미지 쌍을 마이닝 + LLM으로 instruction 합성 → **36.7M (query img, instruction, target img)** 트리플릿.
- **우리 적용 판정: NO(instruction-conditioned retrieval 정의 인용)**. 36.7M 웹마이닝 트리플릿(소규모/1주/무대규모 제약 밖), query 이미지 대상 instruction(순수 텍스트 아님), SigLIP2 아님, training-free 레시피 없음. **용도**: positioning 시 "instruction-conditioned retrieval" 정의 + 우리가 대신 싼 text-only LoRA + training-free 보정으로 텍스트측을 정렬한 이유 설명.

## 테마 6 — 백본 자체 (이미 채택했거나 스왑 부적합)

### 13. SigLIP 2 (우리 백본)
- 출처/인용: arXiv 2502.14786 (2025) · **864회**
- 아이디어: sigmoid 대조손실 유지 + LocCa 캡션/디코더, SILC/TIPS self-distillation+masked-prediction, online data curation, multilingual WebLI. 모든 스케일서 SigLIP1 상회.
- **우리 적용 판정: 이미 채택(method anchor)**. **이것이 우리 백본**(siglip2-base-patch16-384). 인용: (a) multilingual WebLI 인코더라 zero-shot 한국어 검색이 비자명하게 됨, (b) 텍스트 타워가 text-only LoRA로 적응하는 레버. **조치 불필요**(vision cached/frozen). 유일한 업그레이드 후보 = 더 큰 변형(L/16, So400m): 가장 싸고 낮은 리스크의 headroom이나 (F1)서 gold 무유의, 갤러리 588 재인코딩(trivial)만 강제. 백본은 training-free, 우리 적응은 아님.

### 14. AIMv2: Multimodal Autoregressive Pre-training of Large Vision Encoders
- 출처/인용: arXiv 2411.14402, **CVPR 2025** · **102회**
- 아이디어: 대조정렬 대신 멀티모달 autoregression — vision 인코더 + causal 디코더가 이미지 패치+텍스트 토큰 자기회귀 복원. 사전학습 후 **텍스트 타워 폐기, 이미지 인코더만 유지**.
- **우리 적용 판정: NO(함정 — related-work 한 문장)**. 이미지 인코더만 배포 → **정렬된 텍스트 임베딩 공간 없음**, text→image drop-in 아님. 한국어 쿼리를 같은 공간에 넣으려면 새 텍스트 인코더 학습 필요(1주/소규모 밖). 용도: "생성형 사전학습이 VLM vision 백본에 대조보다 강하다"는 2024-25 최강 증거 한 문장.

### 15. Data Filtering Networks (DFN-2B/5B CLIP)
- 출처/인용: arXiv 2309.17425, **ICLR 2024** · **257회**
- 아이디어: 데이터 필터로 쓰는 작은 CLIP의 품질이 그 자체 downstream 정확도와 거의 무관 → 좋은 필터로 거대 풀 큐레이션 시 SOTA 학습셋. 데이터-큐레이션 레시피.
- **우리 적용 판정: NO→PARTIAL(데이터 큐레이션 아이디어 인용)**. DFN CLIP은 English-centric → 한국어서 multilingual SigLIP2보다 열세 + 스왑 시 캐시 무효+LoRA 재학습. **유용한 부분은 큐레이션 아이디어**: 로컬 LLM으로 7k user-style 한국어 쿼리 생성/큐레이션(타깃 분포에 텍스트측 맞춤)을 개념적으로 동기부여 → **distribution-gap 가설 직접 지지**. "타깃 분포에 맞춰 학습 분포를 큐레이션"의 방법론 anchor 인용. non-training-free.

### 16. EVA-CLIP-18B: Scaling CLIP to 18B
- 출처/인용: arXiv 2402.04252 (2024) · **108회**
- 아이디어: 최대 오픈 CLIP(18B), EVA progressive distillation+MIM. 고정 데이터서 27벤치 zero-shot 80.7%. 깨끗한 weak-to-strong 스케일링.
- **우리 적용 판정: NO(인용만)**. 18B는 A6000 단일GPU 재학습 밖, English-centric(한국어 약), 재인코딩+LoRA 비현실. **유일 가치**: "더 큰 CLIP은 source 분포서 계속 도움" canonical 인용 + 우리 발견(병목은 caption-vs-query 분포갭과 N=30 검정력이지 인코더 스케일 아님) 대비 → 스케일은 우리 binding 제약을 못 푼다.

## 테마 7 — Hard-Negative / Fine-Grained 합성 학습 (의도적으로 스킵한 표준 레시피)

### 17. FG-CLIP: Fine-Grained Visual and Textual Alignment
- 출처/인용: arXiv 2505.05071, **ICML 2025** · **77회**(Google Scholar)
- 아이디어: FineHARD(~1.6B 롱캡션 쌍 + 12M 이미지 40M region box + LLM(Llama-3.1-70B)이 **속성 swap**한 10M hard negative). global+region+hard-negative 손실로 CLIP 학습.
- **우리 적용 판정: PARTIAL(method는 스킵, 속성-swap 아이디어만 선택적)**. from-scratch 스케일(수십억 쌍, region box) → 소규모/1주/text-only-LoRA 밖이고 region/patch 특징은 우리가 pooled만 캐시해 부재. **이식 가능 1개**: **속성-swap hard-negative 생성**(객체 고정, 색/핏/패턴/소매 속성 변경, 로컬 EXAONE/Qwen으로) — 패션서 속성이 핵심이라 한국어 속성-대조 학습 쿼리에 직접 재사용. **판정**: 모델 스킵, 선택적으로 LLM 속성-swap negative 패턴만, 단 (F1)서 gold 유의 이득 기대 0.

### 18. TripletCLIP: Compositional Reasoning via Synthetic Vision-Language Negatives
- 출처/인용: arXiv 2411.02545, **NeurIPS 2024** · **56회**(S2)/60(Scholar)
- 아이디어: in-context LLM으로 의미-뒤집는 hard-negative 캡션 생성 → t2i 생성기로 hard-negative **이미지** 합성 → (pos-txt,pos-img,neg-txt,neg-img) 4중쌍 triplet 대조학습. SugarCrepe +9%p.
- **우리 적용 판정: NO(의도적으로 스킵한 표준 레시피 인용)**. vision+text 결합 대조학습 + 합성 negative 이미지 + 도메인 t2i 생성기 필요 → frozen cached-vision, text-only-LoRA와 비호환. **용도**: 우리가 추구하지 않은 canonical hard-negative-compositionality 접근으로 인용(이미지측 학습 없음; (F1) 천장서 compositionality 이득 무유의). gold 기대값 ~0. hard-negative 학습을 피한 이유 프레이밍.
